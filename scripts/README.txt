yy输入法 1.0

【安装】双击「安装.bat」，弹出管理员确认时点「是」。
        装好后按 Win+空格 切换到「yy输入法」。
【卸载】双击「卸载.bat」。你的设置和自造词会保留。

【怎么打字】
  打拼音，空格选第一个，数字键选别的；- = 翻页；回车把字母原样上屏；Esc 取消
  单按 Shift：中/英切换（拼音打到一半按 Shift，字母原样上屏并切到英文）
  简拼：zg → 中国、这个；bjdx → 北京大学
  隔音符：xi'an → 西安
  英文单词直接打：hello、wifi
  rq 出日期，sj 出时间，xq 出星期
  以词定字：打 xianzai 按 [ 上屏「现」，按 ] 上屏「在」
  v 模式：v123 → 一百二十三 / 壹佰贰拾叁 / 壹佰贰拾叁元整；v1+2*3 → 7
          v 加符号码出特殊符号：fh 常用 jt 箭头 sx 数学 dw 单位 xl 希腊 xh 序号
          bd 标点 jh 几何 bq 括号 py 带调拼音；只打 v 会提示这些
  emoji：打 kaixin、haha、mao 时候选里跟着 😄 🐱，设置里可以关
  鼠标点候选也能选，滚轮翻页

【AI】（先在设置文件里填 DeepSeek 的 api_key）
  打拼音时按 Tab：AI 把整串拼音转成句子，再给几种接着写的说法
  选中一段文字按 Ctrl+Alt+空格：AI 给出三种改法（润色 / 更正式 / 更口语）
  没选中文字时按 Ctrl+Alt+空格：AI 照着前文往下写
  选中文字按 Ctrl+Alt+T：翻译，选择候选译文替换原文；Esc 取消
  默认中文译英语，其他语言译简体中文，可在设置里修改目标语言

【设置窗口】
  右键任务栏「中/英」→「设置…」，或未组字时按 Ctrl+Alt+O
  输入与习惯：方案、候选个数、本地整句优化、记词、日期时间、emoji、自定义短语
  AI 娘皮肤：10 款角色皮肤、7 款经典配色、跟随系统、自定义皮肤
  可选择横竖排、字体字号，查看即时预览，或关闭候选框的角色装饰
  AI 与翻译：接口、模型、密钥、代理、超时、翻译目标语言
  快捷键：查看和修改 AI 整句、润色/续写、翻译、设置、标点切换
  支持 Ctrl/Alt/Shift 组合键及 F1–F24，空值停用，重复或无效的键无法保存
  单按 Shift 的开关在输入页。空格/数字选词、[ ] 以词定字、回车、Esc 为固定操作
  Ctrl+. 默认切换中英文标点；Win+空格切换输入法由 Windows 管理
  保存后新设置在下次按键时读取（最长约 1 秒），不会清空已有用户词库

【整句优化】
  使用本地语言模型结合词语搭配排序，不联网。设置里可关闭
  模型文件 data\zh-hans-t-essay-bgw.gram 缺失时仍可使用原词频组句

【升级】
  安装保留旧程序文件和用户设置。重新打开需要打字的应用以使用新版
  系统仍占用旧输入法的情况下可注销或重启后使用

【右键任务栏上的「中/英」图标】
  换方案：全拼 / 小鹤双拼 / 自然码双拼 / 微软双拼 / 五笔86
  换皮肤、竖排候选、中英文标点、打开设置文件、编辑自定义短语
  五笔方案里 z 开头打拼音，可以反查字的五笔编码

【你的文件】都在 %APPDATA%\yyime\ 里
  yyime.ini            所有设置（改完保存就生效）
  custom_phrases.txt   自定义短语
  user_dict.txt        输入法学到的词
